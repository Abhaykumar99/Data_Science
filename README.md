# Data Science Learning Repository

A comprehensive collection of Python scripts and Jupyter notebooks covering fundamental programming concepts, object-oriented programming, and data science tools using NumPy.

## Contents

### Core Python Concepts
- **01_problem.py** - Problem-solving exercises
- **01_takingInput.py** - Input handling and user interaction
- **02_matchCase.py** - Pattern matching and conditional logic
- **03_formattingString.py** - String formatting techniques
- **04_loops.py** - Loop structures and iteration

### Data Structures
- **05_listMethod.py** - List methods and operations
- **06_tupleMethod.py** - Tuple methods and immutable sequences
- **07_setMethod.py** - Set methods and unique element handling
- **08_dictionaryMethod.py** - Dictionary methods and key-value operations

### Functional Programming & Advanced Concepts
- **12_lamdaFunction.py** - Lambda functions and anonymous functions
- **11_listComprehension.py** - List comprehension techniques
- **11_list_comprehensions.ipynb** - Interactive notebook on list comprehensions

### Object-Oriented Programming
- **10_class.py** - Class definition and basic OOP concepts
- **10_oops.ipynb** - Interactive notebook on OOP principles

### File Handling
- **09_fileHandling.py** - File reading and writing operations
- **09_file_handling.ipynb** - Interactive notebook on file I/O

### NumPy & Data Science
- **13_numpy.py** - NumPy basics and introduction
- **14_npArray.py** - NumPy array creation and manipulation
- **15_numpySquaring.py** - NumPy array operations
- **16_numpyArray.py** - Advanced NumPy array techniques
- **17_reshaping.py** - Reshaping and transforming NumPy arrays
- **16-17_Creating_numpy_arrays.ipynb** - Interactive notebook on array creation and reshaping
- **13-14-15_Speedtest.ipynb** - Performance comparison notebook

### Supporting Files
- **data.json** - Sample JSON data file
- **text.txt** - Sample text file

## Getting Started

### Prerequisites
- Python 3.x
- NumPy
- Jupyter Notebook (for .ipynb files)

### Installation
```bash
pip install numpy jupyter
```

### Running the Files
**Python Scripts:**
```bash
python filename.py
```

**Jupyter Notebooks:**
```bash
jupyter notebook filename.ipynb
```
